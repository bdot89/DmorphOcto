🚀 Want a LOT more models? The ported pack

An optional set of extra patch files adds looks from later expansions: 8,157 creature looks, 2,193 mounts, 12,798 weapons and shields, 36,091 armour looks, 915 armour sets and 33 weapon glows from The Burning Crusade to Mists of Pandaria. They show up in DMorph's lists under "Ported (later expansions)", and friends with the same pack see each other's ported looks. DMorph works fully without it. The pack is Blizzard's art, so it's never on GitHub: it's shared privately, and installed with one double-click on Install Ported.bat.

🛠️ Install in two minutes

  1. In OctoLauncher, tick the vanillaHelpers mod.
  2. Download DmorphOcto.zip, Extract All, and move the DmorphOcto folder from it into OctoWoW\Interface\AddOns\.
  3. Close the game, open that folder and double-click Install DmorphHelper.bat (if Windows warns you: More info, then Run anyway). It adds the glows, real skin, face and hair, the size slider, the weather and the time of day. Do it again after each update.
  4. Start the game from OctoLauncher and click the minimap button, or type /dmorph.
  5. The Setup button at the bottom of the window is green when it all works. Red? Click it: it says what isn't running and how to fix it.
