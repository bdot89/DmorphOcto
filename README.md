# 🦄 DMorph for OctoWoW

![DMorph banner](docs/banner.png)

### Become anything. Ride anything. Wear anything. ✨

**DMorph** is a free morph addon for WoW 1.12 (OctoWoW), **version 2.30.0**. Turn into a dragon 🐉, ride a mechanical chicken 🐔, swap your race 🧝, light your blade on fire 🔥, make it snow in Orgrimmar ❄️, and dress up in any armour set in the game 🛡️, all from one slick purple window.

> 🔒 **100% client-side and safe:** morphs only change what *you* and other DMorph users see. Everyone else, and the server, sees your real character.

## 🛠️ How to install

It takes about two minutes. ⏱️

### Step 1: Turn on VanillaHelpers ✅

1. Open OctoLauncher.
2. In its list of mods, tick **vanillaHelpers**.

DMorph needs it. Without it, nothing can morph.

### Step 2: Put DMorph in your AddOns folder 📁

1. [**Download DmorphOcto.zip**](https://github.com/bdot89/DmorphOcto/releases/latest/download/DmorphOcto.zip).
2. Right-click the ZIP and choose **Extract All**, then **Extract**.
3. Inside you'll find a folder called **DmorphOcto**. Move it into your game's AddOns folder, so it ends up like this:

   OctoWoW\Interface\AddOns\DmorphOcto\DmorphOcto.toc

(Used GitHub's green **Code > Download ZIP** button instead? Then the folder is called **DmorphOcto-main**: rename it to **DmorphOcto**.)

### Step 3: Run the installer 🪄 (for glows, real skin, face and hair, size, weather and time of day)

1. Close the game completely.
2. Open the folder: OctoWoW\Interface\AddOns\DmorphOcto
3. Double-click **Install DmorphHelper.bat**
4. If Windows shows a warning:
   - "Windows protected your PC": click **More info**, then **Run anyway**.
   - "Do you want to run this file?": click **Run**.
5. A black window opens and ends with "DmorphHelper is installed". Press any key to close it.

You can skip this step: everything else still works, just without glows, real looks, size, weather and time of day.

### Step 4: Play! 🎮

1. Start the game from **OctoLauncher** (not WoW.exe).
2. Click the polymorph button by the minimap 🐑, or type **/dmorph**
3. Check the **Setup** button at the bottom left of the window:
   - 🟢 Green "Setup OK": you're ready. It also shows which DmorphHelper version is running (for example "Helper v16").
   - 🟡 Yellow "Old helper": close the game and run Install DmorphHelper.bat again.
   - 🔴 Red "Setup: fix me": click it. It tells you what isn't working and how to fix it.


## 🔄 How to update

1. [Download the ZIP](https://github.com/bdot89/DmorphOcto/releases/latest/download/DmorphOcto.zip) again and replace your DmorphOcto folder with the new one (Step 2).
2. Close the game and double-click **Install DmorphHelper.bat** again (Step 3).
3. Start the game from OctoLauncher.

A ported pack (see below) keeps its list in its own folder, Interface\AddOns\DMorph_Ported, so replacing DmorphOcto doesn't remove it. Packs installed before DMorph 2.15.5 kept the list inside DmorphOcto: if your ported models are gone after an update, close the game and double-click **Install Ported.bat** in your pack folder once more.


## 🆘 If something goes wrong

- **"VanillaHelpers isn't running":** close the game completely (check Task Manager), then press Play in OctoLauncher. Don't start WoW.exe directly. Make sure vanillaHelpers is ticked.
- **Setup says DmorphHelper is "not running" or "older":** close the game and double-click Install DmorphHelper.bat.
- **The installer says "The game is running":** close the game, wait a few seconds, try again.
- **The installer can't find the game folder:** DmorphOcto isn't in OctoWoW\Interface\AddOns. Move it there.
- **The game won't start after installing:** double-click **Remove DmorphHelper.bat** in the DmorphOcto folder.
- **DMorph doesn't show in game:** check the folder name and place (Step 2), and that DMorph is ticked in the AddOns list on the character screen.
- **You turned invisible:** that model can't show in your game. Press Reset model.
- **The game crashes with ERROR #132 at 0x0069C... (often with UnitXP_SP3):** a view distance (farClip) above 777 overflows a buffer in the game. DmorphHelper (v7) makes that buffer big enough; without it, type /console farclip 777


## 🎮 Using DMorph

Open the window with the minimap button, /dmorph, or a key under Key Bindings > DMorph. Escape closes it.

- **Every list tab** has a preview box on the right: it shows what you hover (else what you have on). Mouse wheel or **- / +** zooms, drag turns it, right-drag moves it, **Reset** puts it back. **Previous / Next** under it put on the one above or below in the list.
- **Dressing room (left):** your character. Drag to turn, mouse wheel to zoom, right-drag to move. The Size slider under it changes your size in 1% steps (mouse wheel over it for one step; right-click: normal size). A race morph gets that race's size by itself (a Tauren as a Human is human-sized) unless you picked one.
- **Item slots around the model:** left-click for items for that slot, right-click for your own gear. A purple frame marks a morphed slot; a hidden slot shows the empty-slot picture.
- **Reset model / Reset everything:** your own body back / clear every morph.
- **Models tab:** every model. Click one to become it. Right-click to add it to Favourites. **Grid view** shows 8 turning models at a time instead of the list.
- **Mounts tab:** pick which mount gets the skin, then click a model. Previous / Next step through the list. Remove skin takes it off.
- **Favourites tab:** your starred models and mount skins.
- **Races tab:** click a portrait to become that race with your own face. The arrow rows change skin colour, face, hair and facial hair. The dice picks a random look.
- **Glows tab:** pick main hand, off hand or ranged, then click a glow. Glows from a ported pack say "TBC-MoP"; type "ported" in the search box to list only those.
- **Items and Sets tabs:** filter by type, quality and source (ported items and sets have their own "Ported" filter). Hover an item or set to see your character wearing it, then click to wear it. **Invisible** (Items tab) shows nothing in that slot. **Hold** (Items tab, main and off hand) wears a weapon as a one-hander (one-hand stance, sheathed at your side) or a two-hander (two-hand stance, on your back), whatever it really is. The off hand also lists two-handers, held one-handed there, so you can dual-wield two of them. The preview keeps your zoom from item to item. **Own gear: hidden / shown** (Sets tab) picks whether the slots a set has no piece for show nothing (the default) or your own gear.
- **Slutmog tab:** revealing pieces of every slot; the buttons narrow it to chest, shirt, legs, feet or OctoWoW's Unseen Fashion items. **Birthday suit** (also at the top of the dressing room) shows no armour at all.
- **Wardrobe tab:** save and load whole outfits.
- **Weather tab:** pick clear skies or light, normal or heavy rain, snow or sandstorm; the Strength slider fine-tunes it. Time of day: Dawn, Noon, Dusk, Midnight or the Time slider. Server's weather and Real time give the real ones back. Only you see them; weather shows outdoors only.
- **Setup (bottom left):** shows whether everything works, which DmorphHelper version is running, and how to fix what doesn't.
- **Sharing (bottom):** whether others see your morph, and whether you see theirs.

### ⌨️ Chat commands

Type these in the chat box. They never reach the server. Each also works after /dmorph (for macros).

- **.morph 4527** - become a creature by its display ID (.morph 0 resets)
- **.race 1-10** or **.race nightelf** - 1 Human, 2 Orc, 3 Dwarf, 4 Night Elf, 5 Undead, 6 Tauren, 7 Gnome, 8 Troll, 9 Goblin, 10 High Elf
- **.gender** - swap the gender of your race
- **.item 1 2955** - morph one item slot (0 resets it)
- **.mount 4527** - skin for all your mounts (.mount 0 removes it)
- **.scale 1.5** - your size (.scale 0 resets)
- **.weather rain heavy** - the weather: clear, rain, snow or sandstorm, then light, heavy or 5-100 (.weather off: the server's)
- **.time 22:30** - the time of day on your screen, or dawn, noon, dusk, night (.time off: the real time)
- **.glow mainhand 1900** - a weapon glow (0 = none, own = yours)
- **.demorph** / **.demorph all** - reset your model / reset everything
- **.outfit save name** / **.outfit name** / **.outfit delete name** - save, wear or delete outfits
- **.share on/off** / **.share others on/off** - sharing with other DMorph users
- **.dmorph check** - is everything working, and how to fix it

Item slots: 1 head, 3 shoulder, 4 shirt, 5 chest, 6 waist, 7 legs, 8 feet, 9 wrist, 10 hands, 15 back, 16 main hand, 17 off hand, 18 ranged, 19 tabard.


## 💡 Good to know

- Only friendly players can be morphed on your screen. Other DMorph users' morphs show when you target them, mouse over them or group with them (straight away with SuperWoW).
- During a race morph your faction, languages, skills, flight paths, spells and reputation stay those of your own character (with DmorphHelper v16): NPCs of your faction stay friendly and every flight path you know shows, even as a race of the other faction. Your model, skin and hair stay the other race's.
- With a race portrait you keep your own face and hair. If the other race doesn't have one of your values (say a Tauren hair style on a Gnome), the closest one that race has is used instead, so nothing shows up green.
- Mount skins go on when you mount and come off when you dismount. Flight master birds keep their own look.
- Picked faces are only on your own screen for now. Weapon glows show to other DMorph users with 2.23 or newer (glows from the Ported Pack only to friends who have it).
- Shapeshifting shows your morph instead of the form. Reset your model first if you want the form.
- Models, glows and races from The Burning Crusade onwards aren't in the 1.12 game files. A ported pack (below) adds many models, items and glows; later races can't be added.
- A ported item borrows a normal item while it's on you. The first time you wear one after logging in, the game may still be loading that item: click it again a second later.


## 🚀 Ported Pack (optional)

Want a LOT more models? DMorph has no later-expansion models, and doesn't need them. The Ported Pack adds them: extra patch files with **8,157 creature looks** (2,193 of them mounts), **12,798 weapons and shields**, **36,091 armour looks**, **915 armour sets** and **33 weapon glows**, converted from a newer WoW install, plus a list for DMorph (the DMorph_Ported addon). They show in DMorph's lists under **Ported (later expansions)**. These are Blizzard's files, so the pack isn't on GitHub: 💬 [**DM benito9295 on Discord**](https://discord.com/users/637439763040960564) for the download links.

**✅ Before you start:** DMorph 2.19.0 or newer installed (see How to install), about **50 GB of free space** (the download is about 15 GB, most of it can be deleted afterwards), and the **game closed**.

1. **Download BOTH parts** (Part 1 and Part 2) from the links **benito9295** sends you on Discord. Pick one site, MEGA or File Insane: the files are the same.
2. **Unzip both parts into ONE folder.** Make a folder, for example **C:\DMorphPack**. Right-click **Part 1** → **Extract All**, change the path to **C:\DMorphPack** → **Extract**. Do the same with **Part 2**, into the **same** folder.
   > ⚠️ Windows adds the zip's name to the path: delete that part, so both parts land in the same folder. Don't unzip into the game folder. The folder then has **Install Ported.bat**, **manifest.txt**, **Ported.lua** and 17 patch files.
3. **Install:** double-click **Install Ported.bat** in that folder ("Windows protected your PC": **More info**, then **Run anyway**). It finds your game, checks every file (a few minutes), never replaces OctoWoW's own patches, removes patches from an older pack, puts the list in its own addon folder (DMorph_Ported, which DMorph updates never touch) and installs DmorphHelper. Wait for **"The ported models are installed"**.
4. **Play:** start the game from **OctoLauncher**, type **/dmorph** and pick **Ported (later expansions)**. 🎮

🧹 Afterwards you can delete the two zips and the patch-?.mpq files in your pack folder (the game has its own copy). Keep **Remove Ported.bat** and **install_ported.ps1**: double-click **Remove Ported.bat** to take the pack out again.

DMorph users with the same pack see each other's ported models, mounts and items; everyone else sees your normal look.

**Made the models yourself?** Close the game and double-click **Pack Ported.bat** in the DmorphOcto folder. It copies the ported patches and the list into a **DmorphPorted** folder on your Desktop, with a manifest of every file's checksum. Share that whole folder privately; pack again after every porting run, as friends need exactly the same pack.


## 🧑‍💻 For developers

- **Files:** DmorphOcto.lua is the core (morphs, wardrobe, commands), Share.lua shares morphs between DMorph users, UI.lua is the window. Data/ holds the model, item and set lists. helper/ holds DmorphHelper (C source and DLL).
- **How it works:** DMorph uses VanillaHelpers (SetUnitDisplayID, SetUnitVisibleItemID, SetUnitMountDisplayID) to morph, and ClassicAPI for the 3D previews. DmorphHelper adds weapon glows, real skin, face and hair, size, weather, time of day, and keeps your own race (faction, languages, reputation) during race morphs. It only switches on when it finds VanillaHelpers' hooks in the game.
- **Tests:** powershell -ExecutionPolicy Bypass -File tools\run_tests.ps1 (or lua tests/run_tests.lua with Lua 5.0). tests/layout.lua draws every tab's layout from the test mock into tests/layout/*.svg.
- **Previews** show the whole model using Data/ModelFrames.lua (each model's portrait camera and size, made by tools/build_frames.ps1; and Data/PortedFrames.lua for the ported pack, only used when the pack ID matches).
- **Rebuilding the lists after an OctoWoW update:** close the game and run powershell -ExecutionPolicy Bypass -File tools\update_from_game.ps1
- **Building DmorphHelper:** sh helper/build.sh with 32-bit MinGW (on Windows: winlibs i686, from Git Bash).
- **Releases:** the download is a GitHub release asset, DmorphOcto.zip, made with git archive (prefix DmorphOcto/, without docs/ and tests/), so the folder inside already has the right name.
- **Ported packs** are made by a separate converter (modern M2 models to 1.12's format, plus the game tables); it isn't published, as it works on Blizzard's files. The pack's list (Ported.lua) is a separate addon, DMorph_Ported, that DmorphOcto.toc names in OptionalDeps so it loads first; DmorphOcto still reads an older Data\Ported.lua (git-ignored) if there is one. build_*.ps1 skip the pack's patch files.
- Written for the game's Lua 5.0: no #, no %, no string.match.
